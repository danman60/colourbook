## Key Architecture Decisions
- All Supabase tables prefixed cb_ (shared project)
- Admin check via cb_profiles.role column + middleware guard
- AI generation is async: server action creates page with 'pending' status, then fires-and-forgets to /api/generate which uses DALL-E 3 via admin client
- Generation credits: 20 free on signup, decremented per generation
- Stripe checkout sessions for print orders
- Book builder: junction table cb_book_pages with page_order for drag-and-drop ordering
